Time Tracker – React & TypeScript

A personal project exploring React and TypeScript through the development of a practical time-tracking application.

Project Goals

This project serves two purposes:

* Experiment with React, TypeScript, and modern frontend development practices.
* Build a useful application for tracking working time and activities.

Technology

* React
* TypeScript
* Vite

Development Approach

The project provides an opportunity to explore component-based frontend development, TypeScript’s type system, and the React ecosystem.

I’m developing a similar application using Blazor to compare the development experience and architectural approaches of the two technology stacks.

Status

Work in progress. This is an experimental learning project, and features may change as I explore different implementation approaches.
